= Ammitto Australian sanctions data

image:https://github.com/ammitto/data-au/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-au/actions/workflows/fetch.yml"]

This repository stores the Australian Sanctions Office (ASO) Consolidated List
as YAML for Ammitto. The records in `processed/` cover the people, entities
and vessels listed by the Department of Foreign Affairs and Trade (DFAT).

== Source

* Publisher: Australian Sanctions Office, Department of Foreign Affairs and Trade (DFAT)
* List page: https://www.dfat.gov.au/international-relations/security/sanctions/consolidated-list
* File downloaded: https://www.dfat.gov.au/sites/default/files/Australian_Sanctions_Consolidated_List.xlsx

The list holds individuals, entities and vessels subject to Australian
sanctions: those sanctioned by the United Nations Security Council and those
designated by the Foreign Minister under Australia's autonomous sanctions laws.
DFAT notes that, in addition to the vessels on the list, all vessels in the
DPRK vessel class of Australia's DPRK autonomous sanctions framework are also
sanctioned, including all vessels flagged or registered in the DPRK. The
"DPRK Vessel Class" is itself a listing (`au-8599.yaml`), and its
`additional_info` holds the definition.

== Contents

`processed/` holds one file per listing, named after the DFAT reference
number: `processed/au-100.yaml` is reference 100. DFAT publishes each name
variant as its own spreadsheet row; those rows are merged into one record.

`processed/_index.yaml` lists every file, with the time of the last fetch.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `reference` | string | DFAT reference number
| `entity_type` | string | `person`, `organization` or `vessel`
| `names` | list | Name variants: `text`, `name_type` (`Primary Name`, `Alias` or `Original Script`), `script` (ISO 15924 code, such as `Latn` or `Arab`) and, for aliases, `alias_strength` (`Strong` or `Weak`)
| `sanction` | map | `committees` (the regime, such as `Autonomous (Russia)` or a UN committee), `instrument` (the legal instrument), `listing_information`, `control_date`, and true or false flags for `targeted_financial_sanction`, `travel_ban`, `arms_embargo` and `maritime_restriction`
| `additional_info` | string | Free text published with the listing
| `address` | string | Address as published
| `dates_of_birth` | list | Persons only: `raw_value` as published, parsed `year`, `month`, `day`, `precision` (`full`, `month`, `year`, `circa`, `range` or `unknown`) and, where they apply, `circa` and `year_range_from`, `year_range_to`
| `places_of_birth` | list | Persons only: one entry per comma separated part of the published place, as `raw_value` (repeated in `country`)
| `citizenships` | list | Persons only: citizenships as published
| `imo_number` | string | Vessels only: IMO number
| `previous_names` | list | Vessels only: earlier vessel names
|===

`downloaded/` is empty.

== Using the data

Clone or download this repository and run either example from its root
directory.

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/au-*.yaml").sort.each do |path|
  record = YAML.safe_load_file(path)
  name = record["names"].find { |n| n["name_type"] == "Primary Name" }
  puts [record["reference"], record["entity_type"], name["text"]].join("\t")
end
----

Python (requires PyYAML, installed with `python3 -m pip install PyYAML`):

[source,python]
----
import glob
import yaml

for path in sorted(glob.glob("processed/au-*.yaml")):
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    name = next(n for n in record["names"] if n["name_type"] == "Primary Name")
    print(record["reference"], record["entity_type"], name["text"], sep="\t")
----

The same list, harmonized with the other sources into JSON-LD:
https://www.ammitto.org/api/v1/sources/au.jsonld

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 07:15 UTC and commits any change to `processed/`. It runs with
`--prune`, so a listing DFAT has removed is deleted here on the next fetch.

== Development

`processed/` is generated by the Ammitto gem. To refresh it locally, use
Ruby 3.3 (the version selected by the fetch workflow) and Bundler. From
the repository root, run:

[source,shell]
----
bundle install
bundle exec ammitto fetch au --format yaml --output-dir processed --verbose --prune
----

`--prune` removes files for listings no longer present in the fetched list.
Review the generated changes before committing them.

Fetch and parser changes belong in the
https://github.com/ammitto/ammitto[Ammitto gem]; its source models are in
https://github.com/ammitto/ammitto/tree/main/lib/ammitto/sources/au[`lib/ammitto/sources/au/`].
Report data or source-list issues in
https://github.com/ammitto/data-au/issues[this repository].
